### 1.2 删除死代码文件（**仅 3 项**，其余 5 项已证伪为活代码）

> ⚠️ **本节经历 4 轮核查，初版清单的 8 项中 5 项是误报**。教训写在下面，后续判断死代码请照抄本节的五步法。

**核查五步法（缺一不可）**：
1. 类声明全库出现次数；
2. `res/**/*.xml` 引用；
3. **`AndroidManifest.xml` 注册**（漏了这步会删掉 ContentProvider / BroadcastReceiver / Activity）；
4. **`src/test` 引用**（测试夹具会被误判为死代码）；
5. 成员函数的**真实调用点**（`internal object` 的成员不会被"类名"统计覆盖）。

#### ✅ 确认可删（3 项）

| # | 文件 | 证据 | 备注 |
|---|---|---|---|
| 1 | `ui/main/ai/AiChatFragment.kt`（166 行） | 声明 1 次 / XML 0 / **Manifest 0** / test 0；`MainActivity` 只 import `AiChatActivity`，**从不实例化本类**；`fragment_ai_chat.xml` 布局无任何 `R.layout` 引用 → 被 `AiChatActivity` 取代的旧实现 | 布局 `fragment_ai_chat.xml` 一并删 |
| 2 | `model/localBook/EpubMiniLayout.kt` | `internal object`，两个公开成员 `layoutTitle` / `contentHeight` **全库零调用点**（已逐个查函数名，非仅类名） | 同包 `EpubLayoutEngine`/`EpubLayout` 等**仍在用，勿动** |
| 3 | `lib/aliyun/ALiYun.kt`（5 行） | `object ALiYun { fun getToken() {} }` —— **空实现，无调用点** | 与 `lib/aliyun/` 目录一并删 |

#### ❌ 已证伪：**看似死代码，实为活代码，禁止删除**

| 文件 | 误判原因 | 真实引用 |
|---|---|---|
| `receiver/AppUpdateReceiver.kt` | 只在 Manifest 出现 | **`AndroidManifest.xml` 注册为 BroadcastReceiver** |
| `api/ReaderProvider.kt` | 只在 Manifest 出现 | **Manifest 注册为 ContentProvider**（`authorities=${applicationId}.readerProvider`） |
| `ui/rss/subscription/RuleSubActivity.kt` | 只在 Manifest 出现 | **Manifest 注册为 Activity** |
| `help/cache/CacheTaskPersistence.kt` 的 `InMemoryCacheTaskPersistence` | 生产代码零引用 | **`CacheTaskStoreTest` 的测试夹具**（5 处使用） |
| `data/entities/BookChapterReview.kt` | 类零引用、未在 `AppDatabase` 注册 | Room `@Entity`，**删它等于动 DB schema（迁移线红线）**；虽未注册仍按红线**不碰** |

#### ❌ 其他已知误报模式（同样不可按"无引用"判死）

- `ui/book/read/page/SelectionMagnifierView.kt` —— 被 `activity_book_read.xml` + `ReadBookActivity` 引用；
- `ui/main/bookshelf/BookCollectionMosaicLayout.kt` —— 被 `view_book_collection_mosaic.xml` 引用；
- 各类 `Theme*` 自定义 View（`ThemeSwitch` / `ThemeProgressBar` / `ThemeRadioButton` 等）—— **经 XML 标签引用**；
- **184 个"无引用 layout"全部是误报** —— 项目用 ViewBinding（251 个文件），`R.layout.*` 不出现字面量。**布局文件不可按此方法判死**。

**验证**：编译通过 + 全量单测 ≤10 失败。

### 1.4 `utils` 根下 89 个文件移入子目录（**保持包名不变**）

**决策依据**（作者已确认方案 (a)）：**只移动文件位置，不改 `package` 声明** —— 零 import 改动、零行为风险。
代价：包名与路径暂时不一致。这是**刻意的取舍**：先让目录可读，包名统一留作后续可选项。

建议分组（按关注点）：

| 目标子目录 | 内容 | 数量 |
|---|---|---|
| `utils/ext/` | 所有 `*Extensions.kt`（ViewExtensions/ContextExtensions/DialogExtensions/StringExtensions/FlowExtensions/GsonExtensions/MenuExtensions/ConvertExtensions/PreferencesExtensions/FragmentExtensions/RegexExtensions/FileExtensions/EventBusExtensions/CollectionExtensions/PaintExtensions/InputStreamExtensions/ByteArrayExtensions/AnimationExtensions/CoroutineExtensions/MapExtensions/RecyclerViewExtensions/RequestManagerExtensions/ToolBarExtensions/CookieManagerExtensions/ThrowableExtensions/IntentExtensions/JsonExtensions/ArrayListExtensions/ConfigurationExtensions/MutableLiveDataExtensions/MenuItemExtensions/BookChapterExtensions/WindowInsetsExtensions/ActivityResultContracts…） | ~35 |
| `utils/file/` | FileUtils / FileDocExtensions / RealPathUtil / ArchiveUtils / DocumentUtils / EncodingDetect / Utf8BomUtils / ParcelFileDescriptorChannel / AsyncFileHandler / ExportFileWriter | ~10 |
| `utils/image/` | BitmapUtils / ImageUtils / ImageProcessUtils / ImageCropHelper / SvgUtils / DrawableUtils / CenterCropBitmapDrawable / ImageSource / ExportImageSanitizer / RandomColor / ColorUtils | ~11 |
| `utils/net/` | NetworkUtils / UrlUtil / JsURL / DataUrlUtils | ~4 |
| `utils/ui/` | Snackbars / ToastUtils / NavigationViewUtils / ConstraintModify / EffectStyle… / LockableView… | ~6 |
| `utils/`（留根） | 其余具体工具：`ACache`、`QRCodeUtils`、`LogUtils`、`TimeUtils`、`SystemUtils`、`Debounce`、`Throttle`、`ConflateLiveData`、`MD5Utils`、`InfoMap`、`HtmlFormatter`、`ChineseUtils`、`WebSettingsExtensions` 等 | ~20 |

⚠️ **`SurfaceBackdrop.kt`（852 行）不在此列** —— 它是 UI 表面内核，应迁至 `lib/theme/surface/`（见 1.5）。
⚠️ **`BookReadingActivityRouter.kt` 是业务路由**，不该留在 `utils/` —— 建议移入 `help/book/`（需核对引用点）。

**验证**：编译通过 + 全量单测 ≤10 失败。**注意**：`utils/BookReadingActivityRouterTest.kt` 与 `utils/ExportImageSanitizerTest.kt` 的**包路径若变动需同步调整**（本方案保持包名，故测试文件可不动，但目录移动后建议一并归位以保持一致）。
