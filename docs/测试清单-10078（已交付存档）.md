## 1. 必测：玻璃/模糊表面（本轮风险区）

- [ ] **书架页**：底部导航玻璃栏、顶部 Tab 玻璃条、右下搜索圆钮 —— 都应有毛玻璃质感（能透出下层内容），不是纯色块
- [ ] **右上角三个点**（书架）→ 菜单弹出，菜单本身有玻璃底
- [ ] **阅读页**：点中间唤出菜单
  - [ ] 顶部标题栏区域：模糊背景，**能看到文字透上来**
  - [ ] 底部菜单区域：同上
- [ ] **阅读页右上角三个点** → 菜单弹出正常
- [ ] **关闭菜单 → 再打开**：模糊仍正常（**这条最容易暴露表面生命周期 bug**，务必来回 3 次以上）
- [ ] **退出阅读页 → 重进**：模糊仍正常
- [ ] **夜间/日间切换**（阅读页「夜间主题」快捷钮）：切换后所有表面重新渲染，**颜色正确、无残留旧背景**
- [ ] 打开任意设置弹窗（如阅读页「设置」）：**无独立标题栏**，标题是正文首行
- [ ] 阅读样式底部 Sheet（「界面」）：**只有上圆角**，玻璃质感正常

> ⚠️ 表面类 bug 的典型症状：**第一次打开正常、第二次变纯色/变黑/透出错误内容**。请特别关注"重复打开"。

## 7. 已知非缺陷（别误报）

- `adb install` 在小米/HyperOS 上可能报 `INSTALL_FAILED_USER_RESTRICTED` → 需你手动开「USB 安装」开关
- release 包 `run-as` 报 `package not debuggable` → 正常
- 全量单测有 **10 项既有失败**（`CacheTaskStoreTest`×9 + `ReadBookConfigTest.sanitize_clampsUnsafeLineSpacing`），**与本轮改动无关，是长期已知失败**
- 阅读时偶见一帧乱码/空白 → 章节加载中的过渡帧，非缺陷
